# 快速参考卡

> 一页纸速查，覆盖核心原则、铁律、流程节点和自检要点。

---

## 场景判断（第一步）

```
用户说"调研/分析/研究/写报告" → 研究材料（段落论述体）
用户说"PPT/汇报/演讲稿"      → 汇报 PPT（bullet point 体）
不确定 → 主动确认
```

---

## 研究材料 vs 汇报 PPT：核心区别

| 维度 | 研究材料 | 汇报 PPT |
|---|---|---|
| 写作风格 | 段落论述，完整展开 | Bullet point，每条一句话 |
| 深度 | 深度优先，引用丰富 | 结论优先，克制精简 |
| 页面/章节 | 5-8 章节，每章 3-5 子节 | 每页 ≤7 个 bullet |
| 信源 | 12-20+ 条带链接 | 引用研究材料中的数据 |
| 配图 | 5-10 张，每张配 1-3 句总结 | 保留关键图表 |

---

## 通用原则（两种场景都适用）

1. **不夸大不渲染** —— 禁止 marketing 口吻，禁止空洞表述
2. **有数据说数据，没数据说逻辑，没逻辑就删掉**
3. **估算/假设必须标注**，不能模糊带过
4. **逻辑连贯** —— 背景 → 事实 → 分析 → 结论 → 建议

---

## 2 个铁律

### 铁律 1：目标对齐

阶段 1（调研启动）不可跳过。跳过 = SOP 违规 → Changelog 头标注废弃 → 重新对齐。

### 铁律 2：可视化必须有 1-3 句话总结

所有图表/表格紧邻配文字："讲什么" + "关键观察" + "与目标的关系"。缺失 = SOP 违规。

---

## 研究材料 SOP 速查

| 阶段 | 耗时 | 核心动作 |
|---|---|---|
| 1. 调研启动 | 5-10 min | 需求 quote → 范围 → 类型判定 → 风格判定 |
| 2. 调研执行 | 30-90 min | 信源计划 → 背景 → 主体 → 横向对比 → 数据校验 |
| 3. 结构化整理 | 5-10 min | 卷宗 → 大纲 → 信源清单 → 配图计划 |
| 4. 撰写 | 30-60 min | 段落论述 → 配图 → 进度更新 |
| 5. 审核交付 | 10-15 min | 自检 → 润色 → 交付 → （可选）提炼 PPT 版 |
| 5.5 迭代 | 按需 | 精准定位 → 全文锁定 → Changelog → 验证 |
| 6. 复盘 | 事件驱动 | 信源 → 返工 → 反馈 → 沉淀 |

---

## 汇报 PPT 速查

1. 从研究材料提取核心结论和关键数据
2. 按"背景 → 事实 → 分析 → 结论 → 建议"编排
3. 每页 ≤7 bullet，每条一句话
4. 保留关键图表，每张配 1-3 句总结
5. 增加 Q&A 预备页

---

## 自检要点（通用）

- [ ] 所有观点有数据来源或强逻辑依据
- [ ] 推理无断点（禁止跳跃推理）
- [ ] 无夸大和渲染性表述
- [ ] 假设/估算已标注
- [ ] 章节/页面之间有承接关系
- [ ] 可视化元素有 1-3 句文字总结

# 信源 A/B/C 评级指南

> 调研质量取决于信源质量。本指南定义三级信源的判定标准、使用规则和典型示例。

---

## 三级信源定义

### A 级：权威/官方信源

**定义**：信源本身即为事实的产出方或法定披露方，无需二次验证即可引用。

**典型类型**：
- 企业官方财报、年报、SEC/交易所文件
- 政府统计部门数据（统计局、海关、央行）
- 监管机构政策文件、法规原文
- 企业官方新闻稿/公告
- 上市公司招股书、债券募集说明书
- 国际组织官方数据（IMF、World Bank、WHO）

**使用规则**：
- 可直接引用，标注文件名/页码/日期
- 优先引用原文而非二手解读
- 注意时效性：超过 12 个月的数据需标注"截至 XXXX"

### B 级：专业/媒体信源

**定义**：有专业编辑审核流程的媒体或研究机构，信息可信度高但可能存在解读偏差。

**典型类型**：
- 主流财经媒体（财新、36Kr、Bloomberg、Reuters、TechCrunch）
- 券商研报/行业研报（中金、中信、McKinsey、BCG）
- 行业协会数据与报告
- 权威学术机构论文
- 知名数据机构（Statista、IDC、Gartner、Counterpoint）

**使用规则**：
- 可引用，但需标注来源机构和发布日期
- 研报数据需交叉验证（不同券商对同一指标的口径可能不同）
- 媒体报道中的"据知情人士透露"类信息降级为 C 级使用
- 引用研报时标注分析师姓名和机构

### C 级：辅助/非官方信源

**定义**：信息有价值但可靠性未经验证，需交叉验证后才能作为论据。

**典型类型**：
- 自媒体/公众号/知乎/微信公众号文章
- 行业论坛/社区讨论
- 企业官网非公告类内容（博客、产品介绍）
- 新闻报道中的匿名消息源
- 第三方估算数据（无法追溯到原始出处）
- 社交媒体帖子

**使用规则**：
- 不可单独作为论据，必须有 A 或 B 级信源交叉验证
- 引用时明确标注"据 XX 报道/估算，未经独立验证"
- 多个 C 级信源指向同一结论时，可信度上升，但仍需标注
- 在"数据缺口"部分统一说明哪些关键数据仅有 C 级信源

## 信源使用原则

### 1. 口径先行

引用数据前先确认口径：
- 统计口径是否一致（例如"营收"是否含并表/不含并表）
- 时间口径是否一致（财年 vs 自然年）
- 地域口径是否一致（全球 vs 中国区）

### 2. 交叉验证

| 情况 | 处理方式 |
|---|---|
| A 级信源 | 可直接引用 |
| B 级信源 | 建议找第二个 B 级或 A 级交叉验证 |
| C 级信源 | 必须有 A 或 B 级验证后才能作为论据 |
| 仅有 C 级信源 | 标注"公开渠道未查实"，放入数据缺口 |

### 3. 数据缺口处理

发现关键数据缺失时：
1. 明确标注"数据缺口：XX 数据在公开渠道未查实"
2. 说明已尝试的搜索路径
3. 建议用户可能的获取渠道
4. **绝不猜测或编造数据**

## 常见陷阱

- **二手数据当一手用**：看到"据 XX 报道"就引用，没有追溯到原始出处 → 必须找到原始信源
- **研报数据不交叉验证**：不同券商对同一公司同一指标的预测可能差 30% → 取中位数或标注分歧
- **过期数据不加标注**：2023 年的市场数据在 2026 年引用 → 必须标注"截至 2023 年"
- **把企业 PR 当事实**：企业官方宣称的"市场份额领先" → 需第三方数据验证
- **自媒体数据直接引用**：公众号文章的数据 → 降级为 C 级，必须交叉验证

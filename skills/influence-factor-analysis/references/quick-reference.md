# 影响因素分析速查卡

## 一句话流程

**定义结果 → 列候选因素 → 筛区分度 → 定评分阈值 → 先打分后看结果 → 单因素 → 组合因素 → 淘汰弱因素 → 案例解释异常值**

## 6 个常见错误

1. 把“理论上重要”直接等于“适合打分”。
2. 所有因素都塞进总分，导致重复计分。
3. 用 1–10 分制造虚假精度。
4. 先看到结果，再反向调整分数。
5. 因为单因素不显著，就说它“不重要”。
6. 用相关性直接解释因果。

## 因素去留判断

- **有业务意义 + 有区分度 + 可比**：核心评分
- **有业务意义 + 无统一数据**：案例解释
- **无区分度**：删除
- **与其他因素高度重复**：合并/降维
- **结果污染评分**：重定义

## 评分优先级

1. 硬门槛
2. 0/1/2 离散评分
3. 明确阈值的 0/1/2/3
4. 有依据时才加权
5. 最后才考虑复杂指数

## 表格铁律

事实 ≠ 判断 ≠ 结果

每个样本至少保留：
- 原始事实
- 评分依据
- 单项分值
- 替代口径
- 结果变量
